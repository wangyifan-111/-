# XGBoost 模型试验结果

## 运行配置

- 数据：山东现货价格（2026-01-01 至 2026-06-30）、天气预报、电源出力文件
- 回测：2026-06-15 至 2026-06-30，按日期滚动训练，每个目标日只使用此前数据
- 后端：XGBoost 3.4.1，主模型和价差方向分类均实际使用 XGBoost
- 输出：实时价格采用 `RT = DA + (RT - DA)`，区间采用 90% 名义覆盖率的 Conformal Prediction
- XGBoost 单独试验当时的残差：使用 24 小时窗口 ridge 序列回退；随后已在 2026-08-25 安装 PyTorch 并完成真实 TCN 验证

## XGBoost 回测指标

| 目标 | MAE（元/MWh） | RMSE（元/MWh） | 其他 |

| 价差方向 | - | - | 准确率 61.20% |

## 与当前 NumPy Ridge 回退基线比较

同一回测窗口的回退基线为：日前 MAE 58.53、实时 MAE 90.82、价差 MAE 81.71、方向准确率 64.58%。因此 XGBoost 将日前预测 MAE 降低约 17.6%，但实时价格、价差和方向分类在本窗口没有超过回退基线。

结论：XGBoost 对日前价格预测有明显价值，可以作为日前主模型候选；暂不据此宣称它替换整个一体化模型。实时/价差模型仍需更长时间窗口、更多实时市场特征和参数调优后再决定。此前 LightGBM 的 DLL 问题已于 2026-08-25 修复，真实 LightGBM + TCN 的完整回测结果见 `outputs/integrated_price_forecast_lightgbm_tcn_20260825`。
