# 融合模型优化报告

## 1. 实验协议

- 数据：山东现货价格、目标日前可获得的天气预报和电源出力数据。
- 评估：2026-06-15 至 2026-06-30，16 个目标日、384 个小时样本。
- 方法：严格按日期滚动训练；每个目标日只使用该日前数据。
- 候选模型：LightGBM、XGBoost、标准化 Ridge。
- 融合方式：等权平均，以及在前 7 天校准窗口上求解非负且权重和为 1 的自适应凸组合。

## 2. 结果

### 日前电价

| 方案 | MAE | RMSE |
|---|---:|---:|
| LightGBM | 48.30 | 65.42 |
| XGBoost | **47.12** | 64.65 |
| Ridge | 63.63 | 82.74 |
| 等权融合 | 47.44 | **63.04** |
| 自适应融合 | 47.64 | 63.47 |

日前的运营选择为 XGBoost：MAE 最低，且比此前的单一回退模型明显更好。等权融合 RMSE 略低，说明它对极端误差有一定平滑作用；如果业务更看重极端误差而不是平均误差，可以切换为等权融合。

### 实时价格（直接预测基准）

| 方案 | MAE | RMSE |
|---|---:|---:|
| LightGBM | 91.72 | 125.57 |
| XGBoost | 89.92 | 123.22 |
| Ridge | 100.74 | 131.44 |
| 等权融合 | **89.20** | **121.13** |
| 自适应融合 | 90.70 | 122.71 |

实时直接预测中等权融合最稳定，因此保留为实时价格 benchmark。

### 实时价差

| 方案 | MAE | RMSE | 方向准确率 |
|---|---:|---:|---:|
| LightGBM | 89.51 | 125.36 | 60.68% |
| XGBoost | 88.07 | 125.48 | 59.11% |
| Ridge | **83.54** | **118.58** | **66.15%** |
| 等权融合 | 84.83 | 120.60 | 62.50% |
| 自适应融合 | 83.90 | 119.41 | 64.06% |

价差预测选择 Ridge。这里 Ridge 并不是整体模型退化，而是它对价差的平滑性和方向识别更合适。

## 3. 最终选择性融合方案

```text
日前价格       = XGBoost
实时价格基准   = (LightGBM + XGBoost + Ridge) / 3
实时价差       = Ridge
账务一致实时价 = 日前 XGBoost + 实时价差 Ridge
```

在回测中，账务一致的选择性实时价格为：

- MAE：87.93 元/MWh
- RMSE：127.85 元/MWh

这一路径满足 `RT = DA + Spread`，适合接入平台的正式结果；直接实时等权结果作为独立 benchmark 保留。选择性方案不强行要求所有目标使用同一个模型，而是根据各目标的滚动回测结果选择最合适的组件。

## 4. TCN 的处理

LightGBM + TCN 已单独完成回测，但在当前 16 天窗口中日前 MAE 为 48.91、实时 MAE 为 95.26、价差 MAE 为 89.81，未超过上述选择性方案，因此暂不把 TCN 作为生产主路径。TCN 仍保留在研究代码中，后续扩大到更长历史和更多残差样本后再复评。
